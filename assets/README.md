# 이미지 안내

## 앱 소개 원본

프로젝트 소유자가 공개 소개용으로 제공한 자료입니다. 제공받은 원본을 수정하지 않고, 파일명만 기능별로 정리했습니다.

| 경로 | 내용 |
| --- | --- |
| `promo/home.png` | 취미 모임을 발견하는 홈 |
| `promo/discovery.png` | 추천 모임 탐색 |
| `promo/community.png` | 취미 이야기와 활동 공유 |
| `promo/chat.png` | 모임 채팅 |
| `promo/waitlist.png` | 참석 대기와 순번 |
| `promo/attendance.png` | 출석과 참가비 확인 |
| `screenshots/home.png` | 홈 화면 원본 캡처 |
| `screenshots/waitlist.png` | 대기 화면 원본 캡처 |
| `screenshots/chat.png` | 채팅 화면 원본 캡처 |
| `screenshots/community.png` | 커뮤니티 화면 원본 캡처 |

소개 이미지는 제작 당시 화면을 담고 있으며 최신 배포 버전과 차이가 있을 수 있습니다.

## 이전 설명용 이미지

아래 세 장은 UI 설계 설명을 위해 별도로 만든 이미지입니다. 원본 앱 소개 이미지와 구분해 보관합니다.

| 파일 | 성격 |
| --- | --- |
| waitlist-example.png | 모미 대기 화면을 참고한 가상 데이터 설명 이미지 |
| attendance-example.png | 모미 출석 관리 화면을 참고한 가상 데이터 설명 이미지 |

위 세 장은 OpenAI 이미지 생성 도구로 가상 참가자 데이터를 사용해 재구성했습니다. 실제 앱 캡처나 배포 상태의 증거로 사용하지 않습니다.
