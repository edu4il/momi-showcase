# 배드민턴 자동 매칭의 참여 기회와 실력 고려

[모미 소개](../../README.md) · [UI 개선 과정](game-ui-iteration.md) · [참석 확정 처리](offer-confirmation.md)

배드민턴 모임에서 좋은 대진은 팀의 실력만 맞춘 결과로 결정되지 않습니다. 이미 여러 번 뛴 사람, 오래 기다린 사람, 쉬는 사람과 합류한 사람을 함께 고려해야 합니다. 모미에서는 참가 기회를 먼저 살피고, 실력과 파트너 조합을 이어서 고려하는 방식으로 편성을 다룹니다.

## 공평함의 기준을 나누기

참여 횟수, 실력 차이, 같은 파트너의 반복을 하나의 점수로만 더하면 무엇을 먼저 지켜야 하는지 흐려질 수 있습니다. 실력이 잘 맞는다는 이유로 적게 뛴 참가자가 계속 밀릴 수 있기 때문입니다.

현재 실력 기반 편성은 배정 횟수가 적고 오래 기다린 참가자를 기준으로 시작합니다. 그 참가자의 가까운 실력 그룹에서 파트너를 찾고, 조건이 같으면 함께한 횟수가 적은 조합을 고려합니다. 가·나·다·라는 순서가 있는 그룹이며, 정밀한 실력 점수는 아닙니다.

| 기준 | 설계에서 구분한 의미 |
| --- | --- |
| 참여 기회 | 다음 경기를 준비할 때 이미 잡힌 경기와 실제 출전 이력을 함께 고려 |
| 실력 | 비슷한 그룹의 파트너를 우선 고려하고 지나치게 큰 차이를 줄이는 방향 |
| 조합 다양성 | 앞선 조건이 비슷하면 같은 파트너와 상대의 반복을 줄이는 방향 |
| 현장 운영 | 휴식·합류·교체를 반영하고 시작된 경기와 종료 기록은 유지 |

이 기준은 서로 충돌할 수 있습니다. 참가자가 네 명뿐이면 실력 차이가 크더라도 경기를 만들 수 있어야 하고, 늦게 합류한 참가자는 이전 참가자보다 출전 횟수가 적을 수 있습니다. 모든 상황에서 최적이거나 같은 횟수를 보장하는 문제로 취급하지 않았습니다.

## 가상 참가자로 설명하기

| 참가자 | 이미 배정된 경기 수 | 실력 그룹 |
| --- | ---: | --- |
| A | 0 | 라 |
| B·C·D·E | 각 2 | 가 |

실력만 보면 B·C·D·E의 편성이 쉽지만 A의 참여 기회가 계속 밀릴 수 있습니다. 이 상황에서는 A를 기준으로 편성을 시작하는 것이 우선입니다. 이후에 가능한 파트너와 상대를 비교합니다.

## 실행 가능한 작은 예제

[매칭 예제](../../examples/matching.mjs)는 위 기준을 설명하기 위해 별도로 작성한 계산 코드입니다. 가상 참가자 최대 12명을 대상으로 한 경기만 만들며, 참여 횟수가 적은 네 자리를 먼저 정한 뒤 동률 후보의 실력 차이와 파트너 반복을 비교합니다.

실제 엔진의 기준 참가자 중심 탐색, 성별 유형, 지정 파트너, 코트와 경기 상태 처리는 이 예제에서 생략했습니다. 따라서 예제와 서비스의 대진 결과가 같다는 의미는 아닙니다.

```js
import { pickDoubles } from './examples/matching.mjs';

const players = 'ABCDEFGH'.split('').map(id => ({
  id, level: 1, games: 0,
}));

pickDoubles(players); // [['A', 'B'], ['C', 'D']]
```

예제는 참가자 수를 제한하고 가능한 네 명 조합과 세 가지 팀 구성을 비교합니다. 이해하기 쉬운 설명용 탐색이며, 큰 인원에 그대로 적용하는 성능 설계는 아닙니다.

## 검증한 상황

공개 예제의 [테스트](../../examples/matching.test.mjs)는 참여 횟수 우선, 휴식·예약 제외, 실력 그룹 비교, 파트너 순환, 반복 편성, 잘못된 입력을 확인합니다.

8명이 항상 준비 상태이고 실력 그룹이 같을 때 16경기를 차례로 완료하면, 예제에서는 모두 8경기씩 배정됩니다. 네 명만 있는 예제에서는 세 번의 편성 동안 각 참가자가 다른 세 명과 한 번씩 파트너가 됩니다. 이 결과는 해당 조건의 테스트에 한정됩니다.

2026년 10월 30일 Node.js 24.16.0에서 공개 매칭 예제 테스트 6개가 통과했습니다. [예제 실행 안내](../../examples/README.md)에서 같은 테스트를 실행할 수 있습니다.
